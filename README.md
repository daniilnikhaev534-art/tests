# QuickLauncher — лаунчер «Сатурн» для Windows

Космический круговой лаунчер в виде **планеты Сатурн** с реалистичными 3D-кольцами, пружинящей анимацией вылета, золотым звёздным сиянием и приложениями-спутниками по орбите колец.

## Возможности

- **Визуальный стиль «Сатурн» (Planetary HUD)**:
  - **Планета Сатурн**: центральный газовый гигант с реалистичными атмосферными полосами (золотистый янтарь, охра, крем, бронза), 3D-освещением (солнечный свет и терминатор тени), непрерывным вращением облачных бурь и золотистым ореолом рассеяния.
  - **3D-кольца Сатурна**: физически точный наклон (-28°). Задняя половина колец проходит позади планеты, а передняя — поверх неё. Отрисованы сияющее кольцо B, деление Кассини, внешнее кольцо A и полупрозрачное кольцо C.
  - **Приложения на кольцах**: программы расположены вдоль золотых орбит колец Сатурна. При вращении приложения, заходящие за планету, плавно исчезают (3D-окклюзия) и мягко появляются снова спереди.
  - **Интерактивный Hover-эффект**: плавный космический дрейф останавливается при наведении мыши, спутник подсвечивается золотым ореолом, а в центре планеты отображается крупная иконка, название и кнопка запуска.
  - **Вращение колец**: колесико мыши позволяет вручную вращать спутники по кольцам в любую сторону.
- **Космическая заставка (Screensaver / Idle)**:
  - Автоматический переход в режим заставки при отсутствии действий за ноутбуком/компьютером (1–30 минут).
  - Глубокое затемнение экрана (эффект отключенного монитора / открытого космоса) с парящим по центру вращающимся Сатурном.
  - Мгновенный выход при малейшем движении мыши или нажатии любой клавиши.
  - Окно настроек заставки доступно через контекстное меню в трее.
- **Мгновенное и надёжное закрытие лаунчера**:
  - Автоматически убирается при клике в любое место экрана вне спутников.
  - Убирается при переключении на любое другое окно или рабочий стол.
  - Убирается при уводе мыши от планеты.
  - Закрывается по клавише `Esc` или повторному нажатию `Ctrl+Alt+Space`.
- **Классическая панель поиска**: при необходимости доступна через меню трея.
- **Хранение настроек**: `%APPDATA%\QuickLauncher\apps.txt` и `settings.ini`.

## Горячие клавиши

| Клавиша / Действие | Назначение |
|---|---|
| `Ctrl+Alt+Space` | **Открыть / скрыть лаунчер «Сатурн» под курсором** |
| **Клик ЛКМ** по спутнику | Запустить приложение |
| **Клик ПКМ** по спутнику | Меню приложения (запуск, открыть папку, удалить) |
| **Колесо мыши** | Вращать кольца приложений вокруг Сатурна |
| **Цифры 1 – 9** | Быстрый запуск приложения № 1–9 на кольце |
| `←` `→` `↑` `↓` | Переключение выбора приложений по кольцам |
| `Enter` / `Пробел` | Запуск выбранного приложения |
| `Del` | Удалить выбранное приложение |
| `Esc` или клик мимо | Закрыть лаунчер |

## Установка и запуск

1. Установите **AutoHotkey v2**: <https://www.autohotkey.com/>
2. Запустите [launcher.ahk](file:///c:/Users/adminasus/Desktop/лаунчер/launcher.ahk).
3. Нажмите `Ctrl+Alt+Space` в любом месте — Сатурн мгновенно вылетит под курсором!
4. Клик мимо, клик по центру или клавиша `Esc` мгновенно скрывают лаунчер.

## Настройка горячей клавиши

В начале файла [launcher.ahk](file:///c:/Users/adminasus/Desktop/лаунчер/launcher.ahk):

```ahk
HotkeyStr := "^!Space"   ; ^ = Ctrl, ! = Alt, + = Shift, # = Win
```
