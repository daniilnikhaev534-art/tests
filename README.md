# QuickLauncher — быстрый лаунчер для Windows

Меню в трее со списком ваших приложений. Добавляете программу один раз по пути — дальше она открывается в один клик (или по горячей клавише).

## Возможности

- **Трей**: значок в трее, правый клик — список приложений
- **Горячая клавиша**: `Ctrl+Alt+Space` — то же меню прямо под курсором
- **Добавление по пути**: «Обзор…» или вставка пути вручную (.exe, .lnk, .bat, папка…)
- **Иконки**: пункты меню берут иконку из самого exe/ярлыка
- **Хранение**: список в `%APPDATA%\QuickLauncher\apps.txt` (просто текст, легко править руками)
- **Очистка**: если файл пропал, лаунчер предложит убрать пункт из списка

## Установка

1. Ставьте **AutoHotkey v2**: <https://www.autohotkey.com/>
2. Запустите `launcher.ahk` (двойной клик).
3. В трее появится значок — правый клик → **Добавить приложение…**

## Использование

| Действие | Как |
|---|---|
| Открыть список | ПКМ по значку в трее |
| Открыть список у курсора | `Ctrl+Alt+Space` |
| Добавить программу | Трей → *Добавить приложение…* → *Обзор…* → *Добавить* |
| Удалить программу | Трей → *Удалить приложение…* → выбрать пункт |
| Выход | Трей → *Выход* |

## Файл списка

`%APPDATA%\QuickLauncher\apps.txt`

```
; QuickLauncher — список приложений (Название|Путь)
Notepad|C:\Windows\System32\notepad.exe
VS Code|C:\Users\You\AppData\Local\Programs\Microsoft VS Code\Code.exe
```

Формат: `Название|Полный путь` — одна строка на приложение. Можно редактировать в Блокноте, затем перезапустить лаунчер.

## Сборка в .exe (опционально)

1. Скачайте **Ahk2Exe** (входит в дистрибутив AutoHotkey) или используйте проводник AutoHotkey: ПКМ по `launcher.ahk` → *Compile Script*.
2. Готовый `launcher.exe` можно положить куда угодно и запускать без AutoHotkey.

## Автозапуск с Windows (опционально)

1. `Win+R` → `shell:startup` → Enter
2. Положите туда ярлык на `launcher.ahk` (или на скомпилированный `launcher.exe`)

## Горячая клавиша

Сейчас: `Ctrl+Alt+Space`. Другая — измените строку в начале `launcher.ahk`:

```ahk
HotkeyStr := "^!Space"   ; ^ = Ctrl, ! = Alt, + = Shift, # = Win
```
